# Fotos (opcionais)

A página funciona completa sem fotos: os espaços usam ilustrações SVG. Para usar fotos,
coloque os arquivos aqui e preencha os caminhos em `js/fotos.js`.

| Slot | Arquivo sugerido | Conteúdo | Tamanho mínimo |
|---|---|---|---|
| `hero` | `hero.jpg` | Carro de F1 em pista, de preferência noturna ou ao pôr do sol, com espaço livre à esquerda para o texto | 2400 × 1400 px |
| `grid` | `grid.jpg` | Grid de largada / carros alinhados | 2000 × 1200 px |
| `cursos` | `cursos.jpg` | Box, mecânicos ou paddock | 2000 × 1200 px |

Use apenas imagens com licença que permita o uso (próprias, Unsplash, Pexels, Wikimedia
com atribuição) e registre autor e link abaixo. Evite logotipos oficiais em destaque.
